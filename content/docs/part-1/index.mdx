## Packages used in this part

| Package                                  | Used for                                   |
| ---------------------------------------- | ------------------------------------------ |
| `lodash`                                 | npm demo (first third-party package)       |
| `express`                                | Web framework / routing / middleware       |
| `ejs`                                    | Server-side HTML templates                 |
| `mongoose`                               | MongoDB ODM (schemas, models, queries)     |
| `dotenv`                                 | Load `.env` into `process.env`             |
| `nodemon` (dev)                          | Auto-restart the server on file changes    |
| `bcryptjs`                               | Password hashing                           |
| `jsonwebtoken`                           | JWT access tokens                          |
| `multer`                                 | Handling `multipart/form-data` uploads     |
| `cloudinary`                             | Cloud image storage                        |
| `socket.io`                              | Real-time, two-way communication           |
| `@apollo/server`, `graphql`, `graphql-tag` | GraphQL server                           |
| `typescript`, `ts-node`, `@types/*`      | TypeScript with Node/Express               |
