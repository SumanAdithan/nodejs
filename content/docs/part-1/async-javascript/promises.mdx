## What is a Promise?

A **Promise** is an object for a value that will be available **later**. It has three states:

| State       | Meaning                                  |
| ----------- | ---------------------------------------- |
| `pending`   | Still running                            |
| `fulfilled` | Finished successfully → `resolve(value)` |
| `rejected`  | Failed → `reject(error)`                 |

## Creating & consuming

```js
function delayFn(time) {
  return new Promise((resolve) => setTimeout(resolve, time));
}

console.log("Promise lecture starts");
delayFn(2000).then(() => console.log("after 2 seconds promise resolved"));
console.log("end");

// Promise lecture starts
// end
// after 2 seconds promise resolved
```

## Handling errors with reject / catch

```js
function divideFn(num1, num2) {
  return new Promise((resolve, reject) => {
    if (num2 === 0) {
      reject("Can not perform division by 0");
    } else {
      resolve(num1 / num2);
    }
  });
}

divideFn(10, 0)
  .then((result) => console.log(result, "res"))
  .catch((error) => console.log(error, "err"));
// Can not perform division by 0 err
```

| Method      | Runs when                       |
| ----------- | ------------------------------- |
| `.then(fn)` | The promise resolves            |
| `.catch(fn)`| The promise rejects (any error in the chain) |

<Callout>
  `.then()` returns a new promise, so you can chain steps one after another without nesting.
  That's how promises solve callback hell.
</Callout>

## Quick recap

- `new Promise((resolve, reject) => {...})`
- Use the result with `.then()` and handle failures with `.catch()`.
- Chains stay flat. No pyramid of doom.
